Recompute health/shield reward denominator on every reset (same semantic repair as heterogeneous tasks); this implementation is independent of older TS4 results.

VDN sums agent Q. For state/history x, executed joint action u, sensitivity c(x)=mean_i max_{a legal, a != u_i}|Q_i(x_i,a)-Q_i(x_i,u_i)| (0 for no alternatives). This is exactly the existing single-agent counterfactual team-Q change specialized to additive VDN, not QMIX hypernetwork sensitivity. omega=c/mean(c); zero mean undefined. Shared Agent A1=net[2], A2=net[4], each 64 units. Overall score=mean_state(omega*mean_agent(abs(z)))/within-layer mean; strictly >3. Window=last32 complete current-task training episodes; clear FIFO on switch, not replay.

A1 maps incoming net.0 rows/bias and outgoing net.3 columns. A2 maps incoming net.3 rows/bias and all GRU weight_ih columns. Reuse TS3 single-layer actual RMSprop increment scaling: newest boundary set at .1, exiting units linearly recover to1 over100k environment steps; retained selections remain .1. Undefined selection retains previous schedule; valid empty selection releases it. Screen boundaries after phases0/1/2 for protection; phase3 only terminal diagnostics. No interventions baseline. Both layers measured in all groups.

At each boundary, save all scores/activities/IDs/counts, 32-episode CPU batch and model; at first32 episodes of each new phase, measure again without changing protection. Compare previous set with new-task set (distribution plus training effects), and rescore every saved old-task fixed history with current model (parameter-induced change on fixed histories). Store per-unit incoming/outgoing parameter RMS and relative L2 drift, selected versus nonselected descriptive averages. Fixed histories reset GRU per original episode; these are not newly collected on-policy trajectories. Current sensitivity weights can also change with parameters, so fixed-history score drift includes reweighting, not pure activation drift. Scores and drift are proxies, not causal neuron importance; no ablation/causal proof of harmful interference. Selected-vs-unselected contrast is descriptive and unmatched.

Evaluation: current task32 greedy episodes at phase start and every25k training steps; after switch and before any new-phase optimizer update, every previously seen task128 episodes; old tasks32 episodes every100k during new training; stage end all unique seen tasks128 episodes. Independent CPU evaluation environments and fixed per-task seed blocks shared by all methods; restore training RNG, no replay writes. Returning S includes pre-update evaluation of S plus Z/C. Retention is win-rate change from the same old task's previously learned endpoint, and final first-task retention before/after relearning. Report new learning and old retention together.
