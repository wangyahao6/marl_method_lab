# TS4 单前馈 VDN 128：TRHR 与软保护

种子 3535，双方同时使用纯追猎者、纯狂热者、纯巨像，再回到纯追猎者。沿用 TS4 环境及阶段预算 1M、0.5M、0.5M、1M，完整回合切换，奖励上限按当前阵容重算。五组共享无干预 A₁ 前缀，保留在线及目标模型、优化器、回放和可恢复随机状态。每次切换重启探索，回访 A₂ 也重启。新增名义训练量 1M + 5×2M。

对照为基线、状态加权软保护、TRHR、状态加权软保护 + TRHR、等权激活软保护。两种软保护均使用唯一前馈层 A、最近 32 局、层均值归一化得分严格 >3 和历史并集，将输入权重行、偏置和 GRU 三门输入列的实际优化器增量乘 0.1。等权组将有效决策步的激活等权平均。A₁ 末两种筛选在相同的权重和回放上分别执行，此后各分支使用自己的回放。TRHR 参数沿用 TS3，组合组冻结历史保护单元的偏置补偿。

每阶段末在固定环境种子块上评估所有不同的已见任务，每任务 128 局。ACC 对不同任务等权。A₂ 的旧任务均值和 BWT 仅比较狂热者和巨像，追猎者的回访前胜率取 C 末对追猎者的评价，回访增量取 A₂ 末减去该值。FWT 仅包括首次见到的狂热者和巨像。当前任务 AUC 用每阶段的起点、每 25k 环境步和阶段末评价计算，并按实际阶段步数归一化。阶段矩阵区分 A₁ 和 A₂。

每 100 次 learner 更新保存各单元激活率、补偿、保护名单、梯度及实际参数增量。采样来源按四个阶段记录，即使 A₁、A₂ 阵容相同，来源仍可区分。条件激活继续按来源阶段、智能体槽位及目标动作可用性分组。结果由统一调度器在分支终态后汇总。
