每个阶段从其胜局记忆中取最优与次优合法动作 Q 差的中位数，随后冻结为该任务 δ。这个规则在有至少两个合法动作的样本上校准集合宽度。并列和分位数插值会影响实际多元素占比，因此保留差值分位数和候选阈值的集合大小、单元素与全合法动作占比。用这些统计核对集合是否经常退化成单动作或覆盖全部动作。
