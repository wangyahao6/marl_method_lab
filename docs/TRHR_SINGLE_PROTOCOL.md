# TRHR 单任务有效性实验

在原版 SMAC 5m_vs_6m 上，对双前馈层 VDN 进行三种子配对比较。两组使用相同的种子 1234、4567、3535、VDN 配置和 2,050,000 个训练环境步。TRHR 使用现有默认控制参数。每对保存初始权重及参数哈希，参数比较不包含 TRHR 专属缓冲区。该地图已有 QMIX 历史记录，但没有可替代此次 VDN 同口径基线的记录。

两组都开启 A2 诊断。按实际训练更新统计，每 100 次更新记录 64 个 A2 单元的回放激活率、偏置补偿、裁剪后的梯度范数、RMSprop 实际增量范数和非零比例。梯度和增量分别对应 A2 的线性层输入行、GRU 三门输入列。训练预算最后一步按时间上限截断并保留 bootstrap。保存独立的终点 checkpoint、常规训练指标、源代码快照、控制器指标与逐窗记录。

训练中每约 10,000 环境步贪心评价 32 局。用每种子的成对曲线在共同区间上的归一化 AUC 描述学习速度，另记录连续三个测试点达到 50% 的步数。独立终点评价对每对两组使用同样的四个环境种子块，每块 32 局。测试局不参与训练统计或环境步预算。

首次发生补偿后，连续三个完整窗口的总体实测激活率达到 5%，定义为观察到持续唤醒。补偿开始前和达到持续唤醒时分别汇总三窗口，比较 TRHR 的激活、梯度和更新，并对照最近训练步的同编号基线单元。该定义只用于分析。训练回放会随策略分化而改变。

每个独立终点评价种子块取基线的前八条轨迹，构成成对固定回放集。比较初始权重/最终权重与零补偿/最终补偿的四种组合，以及最终基线。记录 A2 正激活率、均值及标准差。若有持续唤醒单元，在独立同种子块评价中把这些单元输出替换成固定回放均值，再与原 TRHR 和按终点激活率、标准差匹配的未补偿对照比较。对照候选不足时仅报告唤醒单元替换。均值替换衡量当前策略对输入相关变化的依赖，也可能受固定回放分布与干预引起的策略分布变化影响。单张地图与三个训练种子限定了结论范围。

任务关系、真实参数与资源声明以 results/trhr_single_20261109/plan.json 为准。每对训练结束后做独立评价，所有任务到终态后自动生成曲线、逐种子结果、逐单元明细及报告。
