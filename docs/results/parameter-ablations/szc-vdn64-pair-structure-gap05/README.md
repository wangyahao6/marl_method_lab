# SZC-1M 动作对结构消融：`min_gap=0.5`

批次 `szc_pair_structure_gap05_3535_20261121` 的 **1 个 TD 参考线和 7 个结构分支均完成**。所有任务从同一干净提交 `f63cbe1` 启动；七个分支依赖参考线成功结束，从相同 S 末检查点恢复，模型指纹一致。Seed 3535，双层 VDN64，Stalker → Zealot → Colossus，每阶段 100 万环境步，RMSprop、FT、逐任务 ε。每个阶段末对所有已见任务独立贪心评估，每任务 128 局。

七组均以合法动作旧 Q 的总体标准差归一化差距，分母下限 0.1，先按结构生成候选对，再保留差距至少 0.5 的对。Softplus temperature 和辅助权重均为 1，不使用状态置信度权重。每个状态对动作对取均值，历史任务内对有效状态取均值，有效历史任务之间等权。三组 Random 使用固定 `pair_seed=3535`，从通过筛选的候选中无放回抽样；选择掩码在训练前保存。

## 实际筛选与结构覆盖

七组共同使用合法动作至少 4 个、旧 Q 无并列、通过间隔筛选的对至少 `2N−3` 个的决策位置。S 池保留 **13,006/21,948** 个位置（59.26%），Z 池保留 **12,283/22,346** 个（54.97%）；七组的有效状态哈希分别完全一致。S 池有效位置中，不并列候选对 **290,893** 个，间隔筛选后 **189,506** 个；Z 池为 **242,457 → 163,558** 个。筛掉比例分别为 **34.85%** 和 **32.54%**。这些池级计数只覆盖共同有效位置，不包括已统一排除的位置。

S 池中 K1+Adjacent 与 Matched 都选择 **81,587** 对，其中 **69,832** 对涉及旧 Top-1；Z 池均为 **76,928** 对，其中 **63,819** 对涉及旧 Top-1。归档掩码逐状态验证两者的 Top-1 对完全相同、非 Top-1 对数相同。Random-N-1 与 Random-(2N-3) 的每状态预算分别严格为 `N−1`、`2N−3`，所有已选对均通过 0.5 门槛。K1+Adjacent/Matched 在筛选后不一定保留完整 `2N−3` 对；其 Top-1 比例因此升至 S 池 **85.59%**、Z 池 **82.96%**。以筛选前不并列候选为分母的压缩率，以及以筛选后候选为分母的覆盖率均在[固定掩码诊断](pool_diagnostics.csv)中单列。

[传递闭包诊断](closure_diagnostics.csv)按旧 Q 方向计算所有可达关系，再除以共同有效位置中的全部严格动作对。S 池 K1+Adjacent、Matched 的闭包覆盖率分别为 **28.36%**、**28.18%**；Z 池分别为 **32.37%**、**31.96%**。S 池七组都没有完整严格排序状态；Z 池 K1+Adjacent 与 FRPR 的完整排序覆盖率仅 **0.30%**，Matched 为 **0.07%**。被筛掉的相邻边不会被误记为完整排序约束。

## 与上一批 `min_gap=0` 的边界

[上一批结果](../szc-vdn64-pair-structure-ratio/README.md)中的七个结构分支均从 `c6b7002` 启动。该版 `pair_ablation.py` 对结构组只排除旧 Q 完全相等的对，**没有执行额外的数值间隔筛选**；配置 `min_gap=0` 与其实际选择行为一致。本批使用 `f63cbe1`，新增了 0.5 门槛和共同预算可行状态规则。逐项核对显示两批 S 末恢复模型指纹相同，S、Z 两份参考历史池的 100 个胜局及全部保存字段逐元素相同，TD learner 源码哈希也相同。不过 pair 选择、偏好诊断和部分驱动源码版本不同，且筛选使状态覆盖率和各方法实际动作对预算发生变化。因此上表 ΔACC 是同种子、同参考数据的**跨版本描述性对照**，不能称为严格单变量因果效应。

C 阶段平均偏好损失从 K1 的 **0.0074** 到 FRPR 的 **0.0264** 不等；每 100 次更新抽样的 Agent 偏好梯度范数均值从 K1 的 **0.088** 到 Random-N-1 的 **0.258** 不等。梯度与 TD 梯度余弦、Kendall tau-a、旧 Q 归一化 regret 和 Top-1 保持率见[梯度诊断](gradient_diagnostics.csv)与[历史回放诊断](preference_diagnostics.csv)。这些量是训练中重复采样的描述统计；不同方法的损失、梯度与终点 ACC 没有简单单调关系。
