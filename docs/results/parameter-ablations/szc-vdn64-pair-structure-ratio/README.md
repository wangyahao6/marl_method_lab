# SZC-1M 双层 VDN64 动作对结构与 Top-1 比例消融

批次 `szc_pair_matched_3535_20261119` 共 14/14 个任务正常退出，共计 28,000,162 个实际新增环境步。一条参考线训练 S 和 Z 并各生成 100 个历史胜局。13 个分支从同一 S 末检查点恢复，恢复模型指纹一致。训练 Z 时回放公共 S 池，训练 C 时回放公共 S、Z 池。参考线只走到 Z，参考线的 Z 阶段及 C 训练前评价不继承到分支。

双层 VDN64、seed 3535、镜像 5v5 Protoss，Stalker → Zealot → Colossus。累计切换阈值 1M／2M／3M，按整回合切换，使用逐任务 ε、FT 和 RMSprop。所有消融分支权重与 temperature 均为 1，min_gap 为 0，旧 Q 标准差下限为 0.1。损失依次按状态内动作对、任务内有效状态和各有有效状态的历史任务求均值。阶段末每个已见任务独立贪心评估 128 局。 [实验协议](../../../SZC_PAIR_ABLATIONS.md)

## 动作对与版本核对

- S 池有 21,944/21,948 个有效决策，Z 池有 22,334/22,346 个。全部结构组和比例组在这两份历史池上的有效状态哈希一致。比例组每状态预算偏差计数均为 0，池级实际 Top-1 比例与设定值的差异均小于 0.001 个百分点。
- 已按归档布尔掩码核对 Matched 组逐状态选中 `2N−3` 对且保留 `N−1` 个 Top-1 对。K1+Adjacent 与 Matched 在 S、Z 池的 Top-1 比例分别同为 54.84% 和 55.22%。Adjacent 和 K1+Adjacent 的传递闭包覆盖所有有效状态，K1 为零。Matched 在 S、Z 池分别有 217 和 423 个状态覆盖完整严格排序。
- 参考线、全部结构组及 Ratio-0/20/40 从 `c6b7002` 启动。Ratio-60/80/100 排队期间跨版本，实际从实验主机的 `0b82d8d` 启动。快照核对显示两版的选对实现、任务间损失聚合、TD learner 和协议一致。共享旧 Q 归一化函数经过重构，在存档的 58,190 个 Agent 位置上逐元素一致。每条运行的完整 SHA 和关键源码哈希见运行清单及配置快照。
- TKPR-K1 与 Ratio-100 的两份池级选择掩码哈希相同，终点 ACC 分别为 51.30% 和 50.00%。两者是同种子的独立训练分支，且启动提交不同。这个差值无法单独归因于源码变动或动作对选择。所有结果仅覆盖一个训练种子，比例组的跨版本对照保留 `same_launch_commit` 字段。
