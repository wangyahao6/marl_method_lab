# SZC-1M 动作对间隔与排名距离

七个结构组共用 S 池的 21,944 个有效 Agent 决策和 Z 池的 22,334 个有效 Agent 决策。Adjacent 所选对的旧 Q 差明显小于两个无分层随机组。与 K1+Adjacent 相比，Matched 保留完全相同的 Top-1 对，因此差异全部来自非 Top-1 对。Matched 约三分之二的非 Top-1 对跨至少两个名次，其逐状态平均旧 Q 差更大。在同一份冻结旧 Q 上代入训练损失，差距的变化足以让 Matched 的损失参照值下降。实际训练损失、梯度和胜率还受到各分支模型及在线轨迹的影响。

## 输入与统计口径

从同一参考线的 `action_set_memory/phase0000/success.th` 和 `phase0001/success.th` 读取各 100 条胜局及保存的 `old_q_values`、合法动作和决策标记。Z 训练阶段使用 S 池，C 训练阶段使用 S、Z 池。Z/S 与 C/S 是同一份固定数据和掩码。CSV 的阶段字段标明使用位置，计数不随训练更新重复累加。离线诊断无需重算旧 Q 或运行环境。

逐条核对七个分支的启动记录、协议和源码包。七个结构组均实际启动于 `c6b7002560c9827061e2f543be318f32cafb5622`。脚本从每组各自的包载入 `decision_masks`、`reference_order` 和 `select_pairs`，验证模块 SHA-256，使用配置中的 `min_gap=0`、`q_scale_floor=0.1`、`pair_seed=3535`。两个历史池的 14 份掩码均与原选择文件逐元素一致，且复核了有效状态和保存掩码的哈希。

- **归一化差距**为 `abs(Q_old[i] − Q_old[j]) / scale`。分母直接使用归档 `reference_order` 返回的 `scale`，即合法动作的总体标准差与 0.1 的较大值。诊断使用合法旧 Q 无并列的共同状态。
- **排名距离**为两端点在合法旧 Q 严格降序中的名次差。Top-1 对至少一个端点为旧策略首选。非 Top-1 对的两个端点均为旧策略的其他合法动作。
- **分布**分别以动作对、状态内均值、状态内中位数为观察单位输出均值、总体标准差、分位数和极值。状态级计算先在单个决策内求值，再给状态等权。分距离的差距统计仅包含至少一个该距离所选对的状态。分距离的状态内份额以该类别有选中对的全部状态为分母，未选中该距离记 0。`eligible_pair_coverage` 的分母是共同状态上该类别和距离的所有合法候选对。
- **配对**以同一池、回合、时刻、Agent 的合法动作集合为单位。`intersection_fraction` 是交集除以任一方法的等额预算，Jaccard 是交集除以并集。配对表每个状态只写一次，S 池由 `training_phases=1|2` 标记。CSV 的 `adjacent_*` 列在配对表中指 K1+Adjacent。

## Adjacent 的旧 Q 差更小

| 历史池 | Adjacent | Random-N-1 | Random-(2N-3) | FRPR | TKPR-K1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| S | 0.307 | 0.717 | 0.716 | 0.717 | 1.135 |
| Z | 0.336 | 0.744 | 0.742 | 0.740 | 1.187 |

表中为全部所选对的逐状态均值再跨状态平均。按动作对等权时，Adjacent 的中位数为 0.200／0.209，Random-N-1 为 0.569／0.558，Random-(2N-3) 为 0.570／0.558。只看非 Top-1 对，Adjacent 的逐状态均值为 0.250／0.269，两个随机组分别在 0.535–0.536／0.538–0.541。差异在两种加权方式和非 Top-1 子集中均存在。TKPR-K1 只选首名到其余合法动作的对，覆盖相邻与远距离，平均差距在这七组中最大。

## Matched 与 K1+Adjacent 的差异在哪里

两组每个状态的 2N−3 个选中对中，N−1 个 Top-1 对逐元素相同。K1+Adjacent 的非 Top-1 对全部是距离 1，覆盖每个符合条件的这种对。Matched 在两池选择的非 Top-1 对全部落在距离 1–8。主要差异来自距离 2–4，合计分别占其非 Top-1 对的 58.04% 和 57.37%。距离 5–8 合计占 7.27% 和 5.49%。

| 历史池 | Matched 非 Top-1 对 d=1 | d=2 | d=3 | d=4 | d≥2 | d≥2 的逐状态平均份额 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| S | 34.69% | 27.13% | 19.31% | 11.60% | 65.31% | 63.44% |
| Z | 37.13% | 28.18% | 19.13% | 10.06% | 62.87% | 60.82% |

在共同的 d=1 内，两组按对平均的非 Top-1 差距几乎一样。S 池为 0.2493／0.2494，Z 池为 0.2678／0.2710，顺序为 K1+Adjacent／Matched。Matched 在 d=2、3、4 的均值则依次升至 S 池的 0.475／0.706／0.958 和 Z 池的 0.509／0.739／0.986。全体非 Top-1 对的中位差距从 0.177／0.183 增至 0.445／0.430。把两组都限制在同一排名距离后，观察到的均值差大幅缩小，说明差距变化主要随排名跨度的构成变化而来。

| 历史池 | 非 Top-1 状态均值 K1+Adjacent → Matched | 状态均值配对差，均值／中位数 | Matched 差距更大的状态 | 全对交集比例／Jaccard | 非 Top-1 交集比例／Jaccard |
| --- | ---: | ---: | ---: | ---: | ---: |
| S | 0.250 → 0.535 | +0.285／+0.252 | 97.29% | 71.42%／0.564 | 36.56%／0.245 |
| Z | 0.269 → 0.540 | +0.271／+0.231 | 96.28% | 72.83%／0.582 | 39.18%／0.268 |

每列交集比例和 Jaccard 均先逐状态算再等权平均。判定差距更大使用 `Matched − K1+Adjacent > 10⁻⁷`。包含 Top-1 对时，两池的平均配对差仍为 +0.129／+0.122。相同 Top-1 对提高了全对交集，非 Top-1 子集更能反映这两种结构的选择差异。

## 损失、梯度和优化难度

训练用的是 `softplus(−m)`，其中 `m = sign(Q_old[i] − Q_old[j]) · (Q_current[i] − Q_current[j]) / scale`，实际 temperature 为 1。旧 Q 差的大小用于本诊断。训练项中旧 Q 提供方向和状态归一化尺度，当前有向差距决定每对的损失和 logit 斜率绝对值 `sigmoid(−m)`。

**Matched 偏好损失较低。** 在同一池内设 `Q_current = Q_old`，则 `m = Δ`，可以仅比较所选动作对带来的损失差。两组全部所选对的状态等权冻结 Q 损失，在 S 池为 0.441 → 0.395，在 Z 池为 0.436 → 0.394，均从 K1+Adjacent 降至 Matched。实际训练日志也同向，Z 阶段为 0.17058 → 0.09944，C 阶段为 0.24025 → 0.15609。冻结 Q 对照直接支持一个机制：在相同且与旧排序一致的 Q 上，Matched 所选的较大间隔降低 Softplus。训练中各组的当前 Q 和 TD 更新路径会分化，阶段日志汇总的回放更新次数也不同，这个机制对实际损失差或终点 ACC 的贡献比例无法由当前数据估计。 [训练损失汇总](../update_diagnostics.csv)

**TKPR-K1 的梯度较小。** 在冻结 Q 对照上，TKPR-K1 的平均 logit 斜率为 0.267／0.263，Adjacent 为 0.427／0.421，顺序为 S／Z 池。实际日志里，TKPR-K1 的偏好 Agent 梯度均值在 Z／C 阶段为 0.273／0.418，Adjacent 为 1.935／1.580。较大的旧 Q 差与较小的冻结 Q 斜率相符。完整参数梯度还取决于当前有向差距、`1/scale`、各动作 Q 对参数的导数以及不同状态和动作对梯度的抵消。现有日志只保留汇总梯度，无法拆出各项的贡献。 [训练梯度汇总](../gradient_diagnostics.csv)

**哪个因素更影响难度。** 在损失公式中，当前归一化有向 Q 差直接控制单对 Softplus 和 logit 斜率，排名距离没有独立输入。本批数据中，排名距离改变所选动作及其旧 Q 差分布，也改变非 Top-1 对的覆盖与传递闭包。同一排名距离的旧 Q 差仍有明显离散，例如 Matched 的 S 池 d=2 的四分位区间为 0.244–0.639。当前数据能区分距离构成和旧 Q 间隔变化，也能验证冻结 Q 下的优化代理差异。要估计两个因素各自对真实梯度或性能的影响，需要在同一当前检查点和回放批次上，以匹配差距的不同距离、匹配距离的不同差距分别做对照，并用多个训练种子检验结论。现有终点只有 seed 3535，无法从这些差异推断训练或胜率的因果效应。 [整批实验结果](../README.md)
