# SZC-1M：Top-1 加额外动作对的排名距离实验（A）

**结论范围。** 两个种子中，固定保留全部旧 Top-1 对后，增加 Near、Mid 或 Far 对的终点 BWT 均高于本批 K1；随机匹配对照没有这一趋势。按两种子均值，K1+Near 的 BWT 最高（10.35 pp），K1+MaxGap 的 ACC 最高（49.87%）。两者构成均值 ACC–BWT Pareto 前沿，且各自的优势不等同于跨种子稳定的因果效应。K1+Near 的额外对具有最小 Q-gap、最高排序闭包覆盖和最高偏好梯度；K1+MaxGap 的额外对 Q-gap 最大、偏好梯度较小。这些诊断为机制线索，不能单独判定排名距离与 Q-gap 哪个起决定作用。

## 协议与核验

批次 `szc_pair_distance_2222_3535_20261122`，SMACv2 5v5、双层 VDN64、Stalker → Zealot → Colossus、每阶段 100 万环境步、FT、RMSprop、逐任务 ε、seed 2222 和 3535。每种子一条 TD 共同参考线执行 S、Z 阶段，并在 S 末保存分支快照；七个实验分支从相同 S 末模型、目标网络、优化器及随机状态恢复，使用同一参考线的 S、Z 历史胜局及旧 Q。参考线和七分支共 16 个调度任务，均完成且退出码为 0。每个阶段末对已见任务各做独立贪心评估，每任务 128 局。

共同有效决策位置要求至少四个合法动作、合法旧 Q 无并列。全部方法保留 `N−1` 个 Top-1 对。`N≥5` 时六个扩展组各添 `B=min(N−2,N−3,(N−4)(N−3)/2)` 个非 Top-1 对；`N=4` 时不添对。K1 是没有额外对的基线，因而其总对数与六个扩展组不同。Near、Mid、Far 分别指旧 Q 排名距离 1、2、≥3。Far/Mid 按接近 2/3 与 1/3 的整数配额分配。MaxGap 取归一化 Q-gap 最大的 B 对；随机方法用固定 `pair_seed=3535` 无放回抽样。`min_gap=0`，只排除旧 Q 完全相等的对；合法动作旧 Q 的总体标准差下限为 0.1，Softplus 温度及辅助权重均为 1。每状态先平均选中对的损失，历史任务内平均有效状态，再等权平均有有效状态的历史任务。

逐池从参考线保存的旧 Q、合法动作和历史回合**重建全部固定掩码**，与 14 个分支归档掩码逐元素相同；同一种子、同一历史任务的七组有效状态哈希一致。四个种子×历史任务池中 K1 共选 484,036 对；六个扩展组各选 773,808 对，Top-1 对均为 484,036 个，实际 Top-1 比例 62.55%。S/Z 有效状态分别为 seed 2222 的 22,053/21,593、seed 3535 的 21,944/22,334；对应决策位置分别为 22,066/21,635、21,948/22,346。没有完整严格排序状态，因为预算不足以覆盖所有非 Top-1 相邻边。

两个种子的参考线和前几个分支由 `d4f4255` 启动，随后分支由 `a10c88d` 启动。中途提交增加了独立的 `tkpr_refresh` 方法；本批的 `pair_ablation.py` 和 `pair_distance.py` 源码哈希完全相同，后续修改的采样和历史池路径以 `tkpr_refresh` 为条件，实际共享训练协议字段相同。各运行的启动提交、关键源码哈希及协议快照见 [runs.csv](runs.csv) 和 [configs/](configs/)。因此这是跨 Git 提交、但本方法路径未改变的比较；不把提交 SHA 本身当作一致性证据。

## 终点性能

ACC 为 C 末 S/Z/C 胜率均值；BWT 为旧任务相对各自训练后端点的平均百分点变化。标准差为两种子样本标准差。`ΔK1` 是同种子、同一 S 前缀配对后再取均值，ACC 和 BWT 独立展示。

| 方法 | ACC %，均值±SD | ΔK1 ACC pp | BWT pp，均值±SD | ΔK1 BWT pp | C AUC % |
| --- | ---: | ---: | ---: | ---: | ---: |
| K1 | 46.61±4.79 | — | −0.59±3.59 | — | 36.19 |
| K1+Near | 49.61±2.39 | +2.99 | **10.35±1.93** | +10.94 | 33.66 |
| K1+Mid | 48.31±2.03 | +1.69 | 9.38±1.66 | +9.96 | 33.18 |
| K1+Far | 49.61±1.66 | +2.99 | 5.66±3.04 | +6.25 | 33.26 |
| K1+Far/Mid | 47.66±2.95 | +1.04 | 7.62±3.04 | +8.20 | 35.43 |
| K1+Random-Matched | 46.22±0.92 | −0.39 | −1.56±2.21 | −0.98 | 33.38 |
| K1+MaxGap | **49.87±0.55** | +3.26 | 1.17±4.97 | +1.76 | **36.87** |

| --- | --- | --- | --- | --- | --- | --- | --- |

表内各单元为 ACC %／BWT pp。Near 在 seed 2222 提高 ACC、BWT，但在 seed 3535 相对 K1 降低 ACC 2.08 pp、提高 BWT 9.77 pp。均值 Pareto 前沿为 Near 和 MaxGap；seed 2222 的前沿为 Near、Mid，seed 3535 为 Near、Mid、Far。Far/Mid、Far 和随机组在均值平面被 Near 支配，不能据此忽略其逐种子或学习曲线差异。ACC 同时包含旧任务保持与新任务学习；单独看 C 任务终点，MaxGap 的两种子均值为 51.17%，Near 为 44.14%。完整 FWT、S/Z/C 端点胜率及各阶段 AUC 见 [stage_metrics.csv](stage_metrics.csv)、[summary.csv](summary.csv)和[learning_curves.csv](learning_curves.csv)。共同 S 阶段 AUC 为 seed 2222 的 26.93%、seed 3535 的 24.61%；Z 阶段 AUC 以 MaxGap 44.63%、Far 44.58% 较高，C 阶段以 MaxGap 36.87%、K1 36.19% 较高。终点和曲线并非同一指标。

## 动作对与优化诊断

六个扩展组均额外选 289,772 对。其额外对在四个历史池合并后的分布如下；Q-gap 是逐合法动作标准差归一化后的旧 Q 差距。每个池另有逐状态均值分布、分位数及逐排名距离分布，不只提供池化均值。

| 组 | Near/Mid/Far 额外对数 | 额外对平均排名距离 | 额外对平均 Q-gap | 严格关系传递闭包覆盖率¹ |
| --- | ---: | ---: | ---: | ---: |
| Near | 289,772 / 0 / 0 | 1.00 | 0.261 | 64.9% |
| Mid | 0 / 289,772 / 0 | 2.00 | 0.491 | 56.9% |
| Far | 0 / 0 / 289,772 | 3.68 | 0.906 | 47.5% |
| Far/Mid | 0 / 86,469 / 203,303 | 3.16 | 0.780 | 48.5% |
| Random-Matched | 98,797 / 77,907 / 113,068 | 2.35 | 0.582 | 51.7% |
| MaxGap | 0 / 28,157 / 261,615 | 3.92 | 1.095 | 47.2% |

¹ 对同一有效状态全部旧 Q 不并列对，按选中对的旧 Q 方向做传递闭包；此列以四池全部候选对数加权。K1 为 29.5%。Near 的排序关系覆盖最高，但仍不能完整表达所有严格次序。

C 阶段按种子平均的偏好梯度范数为 K1 0.389、Near 0.821、Mid 0.698、Far 0.463、Far/Mid 0.530、Random 0.682、MaxGap 0.394。Near 的选中对违反率在两种子约 9.5%–9.7%，MaxGap 约 2.1%；前者的偏好损失也更高。**更大的偏好损失或梯度并未对应更差的 BWT**。当前 Q-gap 与排名距离共同变化，不能从这些数据分离二者的因果作用。Top-1 翻转率是训练期间抽样的历史状态指标，也不等同于终点旧任务胜率。逐阶段损失、违反率、翻转率见 [preference_diagnostics.csv](preference_diagnostics.csv)；TD／偏好梯度及余弦见 [gradient_diagnostics.csv](gradient_diagnostics.csv)。
