# SZC-1M：K1 与 Q-gap 匹配的非 Top-1 动作对

**本批结论。** Gap-Matched-NonTop1 在每个有效状态用与 TKPR-K1 相同的 `N−1` 对预算，不包含任何 Top-1 对。它将相对 K1 的逐状态平均 Q-gap Wasserstein-1 距离从随机 Ratio-0 的 S/Z **0.639/0.689** 降至 **0.395/0.456**，但未实现充分匹配。C 末 ACC 为 **34.11%**，高于 Ratio-0 的 **31.25%**，仍低于 K1 的 **51.30%**。这说明最优可行的非 Top-1 gap 匹配在这一个种子里没有追上 K1；由于残余 Q-gap、排名距离、动作对图结构及在线训练轨迹均可能影响性能，**不能把差距直接解释为 Top-1 身份的独立因果价值**。

## 运行来源与核验

本实验复用 `szc_pair_matched_3535_20261119` 的 TD 参考线、`pair_structure_k1` 和 `pair_ratio_0`，只新增 `szc_pair_gapmatched_3535_20261123_pair_gap_matched_non_top1` 一个分支。三条旧运行由 `c6b7002560c9827061e2f543be318f32cafb5622` 启动；新分支由 `3d3d6f312e864f288a734e38f07d2f1f52d86b68` 启动。四条任务均完成且退出码为 0。三个偏好分支的父运行相同，S 末恢复模型指纹均为 `54c9f68d05a423e84bcea663d1d8102dee62382f4e7792bbce0d39bc2d37af0f`。S/Z 成功轨迹与保存的旧 Q 均来自同一旧参考线；[运行清单](runs.csv)、[源码及协议快照](configs/)和[来源清单](source_manifest.json)保存完整标识、源码哈希及历史池 SHA-256。未重训或覆盖旧运行。

SMACv2 5v5、双层 VDN64、Stalker → Zealot → Colossus、每阶段 100 万环境步，seed 3535，RMSprop、FT、逐任务 ε；阶段末对已见任务各做 128 局独立贪心评估。新方法的 `min_gap=0`、`q_scale_floor=0.1`、temperature=1、偏好权重=1。与旧对照相同，每状态先对选中对取 Softplus 均值，历史任务内平均有效状态，再对有效历史任务等权平均。旧源码与新源码的完整哈希不同；已核对 K1、Ratio-0 的归档掩码能由当前同参数选择器逐元素重建，且两版 `ablation_loss` 的 Softplus 核心项及任务聚合公式相同。新增的偏好诊断不进入损失。

在参考线的 S/Z 历史池上，三组有效决策位置分别一致，为 **21,944/22,334** 个，`valid_state_sha256` 完全相同。每组每有效位置均选 `N−1` 对，S/Z 分别选 **124,392/118,223** 对。新方法和 Ratio-0 的 Top-1 对数均为 0，K1 的每对均涉及 Top-1；没有重复或非法对。新掩码在训练前生成，训练归档的 S/Z 掩码哈希与预生成值完全相同。选择用一维动态规划最小化两条排序后 gap 序列的绝对差和，平局以原始动作对索引稳定裁决，不重新抽样。

## Q-gap 匹配质量

归一化 gap 使用 `reference_order`：合法旧 Q 的总体标准差，分母下限 0.1。下表是**按动作对池化**的 gap 分布；[完整分布表](gap_distribution.csv)另含标准差、P25、P50、P75、P90 和极值。[逐状态 W1 与相对误差](state_matching.csv.gz)为每个有效位置保留独立记录。

| 历史池 | 组 | 平均 gap | 中位数 | P90 |
| --- | --- | ---: | ---: | ---: |
| S | K1 | 1.161 | 1.058 | 2.223 |
| S | Ratio-0 | 0.550 | 0.440 | 1.171 |
| S | Gap-Matched-NonTop1 | 0.793 | 0.715 | 1.496 |
| Z | K1 | 1.233 | 1.094 | 2.460 |
| Z | Ratio-0 | 0.553 | 0.424 | 1.214 |
| Z | Gap-Matched-NonTop1 | 0.790 | 0.690 | 1.535 |

| 历史池 | Ratio-0 逐状态 W1 均值 | 匹配后逐状态 W1 均值 / P90 | 匹配后相对误差均值 / P90 |
| --- | ---: | ---: | ---: |
| S | 0.639 | 0.395 / 1.015 | 28.9% / 62.2% |
| Z | 0.689 | 0.456 / 1.231 | 32.0% / 65.3% |

W1 是同一位置两组 `N−1` 个 gap 分别排序后绝对差的均值；相对误差用该位置 K1 平均 gap 作分母。**没有任何有效位置达到完全匹配**。严格旧 Q 排序下，K1 最大 gap 为最高动作与最低动作之差；非 Top-1 候选的最大 gap 至多是第二高动作与最低动作之差。因此 S/Z 每个有效位置都存在不可匹配的最大 gap 尾部，平均最大 gap 缺口分别为 **0.559/0.632**。匹配后平均 gap 仍比 K1 低约 0.368/0.443，不能视为 gap 已控制相同。

选对的排名距离也发生变化。[逐距离分布](rank_distance_distribution.csv)显示 Far（距离≥3）占比：S 池 K1 64.7%、Ratio-0 37.5%、匹配组 62.1%；Z 池为 62.2%、33.8%、57.4%。匹配组在排名距离上也比 Ratio-0 更接近 K1，因此其任何性能改善不能只归因于 gap 匹配。

## 性能与优化诊断

ACC 为 C 末 S/Z/C 胜率平均；BWT 为旧任务相对各自训练后端点胜率的平均百分点变化。Z/C AUC 是该阶段当前任务贪心胜率曲线的时间积分均值。单元为百分比或百分点。

| 方法 | C 末 S / Z / C 胜率 % | ACC % | BWT pp | FWT pp | Z AUC % | C AUC % |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| TKPR-K1 | 21.09 / 75.00 / 57.81 | **51.30** | **+1.56** | 23.05 | **46.43** | **30.49** |
| Ratio-0 | 17.19 / 35.16 / 41.41 | 31.25 | −18.75 | 19.14 | 34.91 | 30.32 |
| Gap-Matched-NonTop1 | 15.63 / 48.44 / 38.28 | 34.11 | −3.12 | 19.53 | 35.60 | 28.45 |

新方法相对 K1 的 C 末差值为 **ACC −17.19 pp、BWT −4.69 pp**；相对 Ratio-0 为 **ACC +2.86 pp、BWT +15.62 pp**。但新任务 C 的终点胜率反而比 Ratio-0 **低 3.12 pp**，C AUC 也较低；ACC 的改善来自旧任务。BWT 的解释须同时看 Z 阶段学习：新方法在 Z 训练结束时的 Z 胜率仅 **45.31%**，低于 Ratio-0 的 **64.84%**；C 末前者为 48.44%，后者降至 35.16%。新方法的较高 BWT 部分来自较低的 Z 阶段参照端点，不能单独概括为更强的绝对旧任务能力。[阶段指标](stage_metrics.csv)、[逐次独立评估](evaluations.csv)、[学习曲线](learning_curves.csv)和[配对差值](paired_metrics.csv)保留原始比较。

在训练期间抽样的历史任务上，C 阶段平均偏好损失为 K1 **0.060**、Ratio-0 **0.218**、新方法 **0.106**；平均偏好梯度范数分别为 **0.418、1.219、0.755**，见[更新诊断](update_diagnostics.csv)、[分历史任务诊断](preference_diagnostics.csv)和[梯度诊断](gradient_diagnostics.csv)。这些量描述约束的优化过程，不能直接推断性能原因。

另用三组 **C 末冻结 Agent** 对同一参考线 S/Z 历史轨迹做离线 Q 前向；在有效状态的全部合法旧 Q 不并列对上计算 Kendall tau-a，同时统计旧 Top-1 仍是新贪心动作的比例。K1 的 S/Z Top-1 保持率为 **98.5%/90.0%**，Ratio-0 为 **76.7%/66.4%**，匹配组为 **70.9%/66.8%**。对应全部候选对的 tau-a 为 K1 **0.723/0.680**、Ratio-0 **0.881/0.764**、匹配组 **0.828/0.764**。全局排序一致率较高并不保证 Top-1 保持率较高；这些是旧轨迹上的离线 Q 诊断，不是环境胜率或独立状态分布上的因果试验。详见[冻结策略诊断](final_policy_diagnostics.csv)。

## 可支持的结论与边界

1. **可直接观察：**给定同一历史状态和相同对数，最优非 Top-1 子集比随机 Ratio-0 更接近 K1 的 Q-gap 分布；在 seed 3535 的 C 末 ACC、BWT 也高于 Ratio-0，但仍显著低于 K1 的 ACC。K1 对旧 Top-1 的离线保持率最高。
2. **尚不能证明：**K1 优势独立于 Q-gap 大小。最大 gap 在每个状态都不可匹配，整体平均 gap 和排名距离仍不同；新分支与旧对照的源码提交不同，尽管本次核验了关键损失和旧掩码行为；当前任务在线轨迹也会随策略变化。只有一个训练种子，不进行显著性判断。
3. **后续验证方向：**若需更强地区分 Top-1 身份、gap 和图结构，可约束在共同可达 gap 区间并同时匹配精确排名距离，或对 Top-1 对作同预算干预；这需要新的实验授权，本报告不将其视为已完成证据。
