## 约束诊断

R2/R3 的训练日志按 Z 阶段的 S 历史池、C 阶段的 S/Z 历史池分别汇总。有效状态是至少有一个通过间隔筛选的锚点动作对的位置。四条完整运行的 C 阶段 S 池中，R2 有效状态覆盖率为 **90.7%／94.0%**（seed 2222／3535），R3 为 **85.9%／90.3%**；平均有效对数分别为 **3.15／3.25** 与 **2.69／2.69**。R3 在同一 S 池上通过筛选的约束更少，故排名位置变化同时改变了有效对数和状态覆盖率。

C 阶段 S 池中，被保护动作在新策略里仍处于原名次的比例：R2 为 **48.9%／52.9%**，R3 为 **41.2%／42.0%**。对应平均新排名约为 R2 **2.28／2.29**、R3 **3.13／3.16**。这些统计来自训练时反复抽样的历史决策，不能视为独立状态样本或单独解释终点胜率。逐历史任务的筛选率、有效对数、排序违反率、新排名直方图及梯度统计见下列 CSV。

本批直接支持 R2 与 R3 的同种子、同父前缀观测比较。它不能确认“保护第 2 名”本身导致更高 ACC：两种锚点在 `min_gap=0.5` 后产生不同数量的约束和有效状态，训练轨迹及后续 Z 池也会分化。与历史 K1 的差值还受运行批次及源码版本影响，需要完成同版本 K1 对照后再做严格三组归因。
