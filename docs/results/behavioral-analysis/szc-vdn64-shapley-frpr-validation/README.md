## 数据划分

使用双层 VDN64 的 SZC 序列（镜像 5v5 追猎者、狂热者、巨像），覆盖训练种子 2222、3535。每个种子各有三个冻结端点，即 Z 后评 S、C 后评 S、C 后评 Z。历史阶段末 FRPR 提供旧 Q 和胜局，VDN-FT 提供目标状态 Q 以及干预后的贪婪执行。标准 FRPR 使用合法动作上三角去重、旧 Q 标准化和 min_gap=0.5，q_scale_floor=0.1。

- **Discovery。** 低 M 数据来自六组 [Pilot](../szc-vdn64-shapley-frpr/README.md) 中通过核验的状态。使用相同的历史环境种子另采 M>12 的状态，每个端点的战斗阶段 × Action Regret 分层至多一个。S 的 Discovery 种子为 91101–91104，Z 为 91201–91204。
- **Validation。** S 使用 92101–92108，Z 使用 92201–92208。先记录独立历史胜局，再按战斗早／中／晚期 × 低／中／高归一化 Action Regret 抽样，每层至多两处，优先覆盖不同回合。归一化 Action Regret 使用 0.1 和 0.5 两个分界。 [原口径](../szc-vdn64-action-regret/README.md)核对 Discovery 和 Validation 的环境种子、SC2 种子及回合标识。Smoke 仅作工程核验。

SC2 引擎种子在建局时设置，源轨迹的初始化条件由现有确定性回放恢复。当前 SZC 配置没有可核验的目标状态后独立重播种接口。因此验证解释范围为**跨独立历史轨迹的关系排序迁移**。在每个 Validation 状态内，四组在同一可重放前缀、同一 FT 后续策略和同一批合法动作分支上配对。

## 精确与近似 Shapley

M≤12 的关系继续完整枚举，并额外用随机排列近似对照。M>12 使用均匀随机排列，在每个排列上累加从空到满的边际贡献。投影和 Softmax 复用原 Pilot，已访问联盟按位掩码缓存。两种方法共用每个合法动作的真实回报和胜负；两种指标都核对效率误差。

每批 128 个排列，至少 512、至多 2,048 个。达到最小预算后，连续两批同时满足以下回报条件即可停止：最近独立批相对之前累计估计的 Top-K 重合比例 ≥2/3，且累计每关系最大变动 ≤0.001 + 0.10 × 本批后最大绝对估计值。保留累计及独立批的 Spearman、Top-K 重合和 Jaccard，以及每关系 Monte Carlo 标准误。常量排名的 Spearman 留空。预算耗尽时使用其估计并标记状态。回报是选择依据，胜率的稳定性单列记录。

## 冻结选择与配对估计

在 Discovery 内按每个 context 的回报 Shapley 转为百分位名次，每个训练种子 × 端点分别拟合有向动作对分数。交叉分层分数以三个伪观测向该关系的全端点均值收缩。未见关系用中性分数 0.5，记录实际入选覆盖率。冻结分数后，在 Validation 中只读取合法关系和分层信息确定 K=min(3,M) 的掩码，再采集每个合法动作的干预回报。用逐一移除 Discovery 环境种子的重拟合量化迁移排名稳定性。

四个联盟为 Empty、Full、Random-TopK、Shapley-TopK。Random-TopK 的 16 个固定随机种子均在相同有效关系集和预算上抽样，状态内平均后参与配对。四组统一使用投影 margin=0、Softmax 温度 1 和标准旧 Q 尺度。累计回报从执行目标动作起算，胜率是分支终局胜负的加权期望。Full 表示冻结 FT Q 投影全部 FRPR 关系后的行为结果。

主估计量是 Validation 中逐状态配对差值的均值。95% 区间用 5,000 次分块 bootstrap，在任务内按环境种子重采样，并保留同种子的所有状态、端点和训练模型。区间反映这批冻结模型在所采样胜局上的变化，研究只包含两个训练种子。关系以局部动作编号定义，跨轨迹攻击槽位可能指向不同个体。
