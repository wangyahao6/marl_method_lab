# SZC-1M · VDN64 · RMSprop 共享前缀

种子 3535，追猎者 S → 狂热者 Z → 巨像 C，每阶段名义 1M 步。使用原版 RMSprop（学习率 0.0005、alpha 0.99、epsilon 1e-5）、FT 回放和逐任务探索退火。阶段末对每个已见任务独立贪心评估 128 局。

TKPR-K1 的 C 末 ACC 最高。TKPR-K1-W 的巨像胜率高 8.59 个百分点，巨像学习 AUC 高 5.11 个百分点，同期追猎者和狂热者胜率分别低 6.25 和 4.69 个百分点。数据只覆盖一个训练种子。

## 运行关联

S 只训练一次，在 1,000,035 步保存检查点，阶段末追猎者胜率为 25.00%。三个分支均从这份检查点和 RMSprop 状态开始，在各自的恢复记录中核对了模型哈希。S 启动于 `6c40042`，三个分支均启动于 `c046e23`。计算完整曲线时按 `parent_run_id` 关联 S。AUC 是当前任务贪心胜率按阶段实际步数归一化的梯形积分。
