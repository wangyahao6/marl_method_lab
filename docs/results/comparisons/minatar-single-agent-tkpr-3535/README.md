# MinAtar · DQN-FT 与 DQN-TKPR-K1，seed 3535

## 问题与结果

在相同的七区间 MinAtar 任务序列上比较独立运行的 DQN-FT 和 DQN-TKPR-K1。两项调度任务均以退出码 0 完成，各训练 3,500,000 环境步，保存了七个阶段检查点。训练源码均为 [`80d7ad6`](https://github.com/wangyahao6/marl_method_lab/commit/80d7ad68abf7b9069e54721d668a233a9de0f7f6)。从保存的检查点独立重做全部贪心评价后，两条运行各 24 条评价记录和保留指标均与训练时记录逐项一致；核对结果见 [verification.json](verification.json)。

| 游戏 | FT 首次学完后 | K1 首次学完后 | FT 最终 | K1 最终 | 最终 K1 − FT |
| --- | ---: | ---: | ---: | ---: | ---: |
| Breakout | 7.35 | 16.35 | 14.65 | 16.24 | +1.59 |
| Freeway | 26.30 | 12.30 | 0.04 | 12.33 | +12.29 |
| Space Invaders | 46.85 | 46.85 | 2.00 | 34.13 | +32.13 |

表中是原始每局平均回报。首次学完后的评价每游戏 20 局，最终评价每游戏 100 局，均为冻结模型贪心策略；因此两列之间的差值也受评价局数差异影响。最终评价的每个游戏和两个方法使用相同的环境种子块。单个训练种子显示 K1 在本次任务序列的最终三个游戏回报均高于 FT，尤其保留了较多 Space Invaders 和 Freeway 表现；这不是跨种子显著性结论。Freeway 首次学完时 K1 为 12.30、FT 为 26.30，不能只看最终保持而忽略新任务学习差异。[逐阶段回报](stage_metrics.csv)与[逐游戏 BWT/遗忘](retention.csv)给出完整端点数据。

## 实际协议与方法是否生效

- 种子 3535；任务序列：Space Invaders → Freeway → Breakout → Freeway → Freeway → Breakout → Breakout。每区间 500,000 步，总计 3,500,000 步。两个方法均为共享六动作 CNN-DQN、固定 ε=0.1、同一网络与优化器配置；游戏发生变化时清空 TD replay，相邻区间游戏相同时保留。环境为官方 MinAtar `v0` 完整动作接口，`sticky_action_prob=0.1`，`difficulty_ramping=False`。生效参数见[逐运行配置](configs/)及[协议说明](../../../../configs/single_agent/README.md)。
- FT 未采集历史参考记忆，也无偏好更新。K1 在三个游戏首次训练后各冻结模型采集 10,000 个状态，保留所有重复状态；唯一状态数分别为 Space Invaders 8,757、Freeway 6,148、Breakout 1,558，见[参考记忆统计](reference_memory.csv)。
- K1 在阶段 1 至 6 分别有 499,937、499,937、499,937、500,000、499,937、500,000 次非零偏好损失更新，合计 2,999,748 次。每 1,000 环境步抽样的[偏好诊断](preference_diagnostics.csv)显示对应阶段均有实际约束；阶段 0 尚无历史任务。这里仅确认方法被执行，不能将两条独立训练轨迹的最终差值单独归因于某一种约束机制。
- 使用 Python 3.8.10、PyTorch 1.12.1+cu113、Gymnasium 0.29.1、MinAtar 1.0.15；训练使用 CUDA。按相同保存配置从七个阶段检查点独立复算评价，结果完全一致。完整模型、历史记忆、逐局日志、调度记录和源码快照保留在实验主机 `/home/wyh/marl_method_lab_minatar/runs/` 对应 `run_id` 目录。

## 公开数据与边界

[运行清单](runs.csv)连接方法、训练提交与配置；[训练摘要](training_summary.csv)记录阶段步数、回合数、偏好更新和记忆规模；[评价](evaluations.csv)包含所有阶段末 20 局评价及最终 100 局评价；[阶段回报](stage_metrics.csv)便于按游戏看遗忘与回访；[训练曲线](learning_curves.csv)为探索策略最近 100 局回报，不能当作贪心评价曲线。原始奖励在三个游戏间尺度不同，不计算跨游戏的平均回报或 ACC。

两种方法是相同种子与任务序列下的独立训练运行，并不共享完整轨迹；第一阶段后策略和采样会分化。本批只有一个训练种子，评价均值不能提供训练种子间的不确定性。阶段 0 至 6 对三个游戏都做了评价，包括尚未训练过的游戏；判断首次学习和旧任务保持时应结合任务序列阅读。
