# TS3 单前馈 VDN 与 TRHR / 软保护

种子 3535，TS3 原五任务：固定我方 2S3Z，敌方 A→E 为 2S3Z、4S1Z、1S4Z、3S2Z、5S0Z。双层 VDN 旧前缀的结构不兼容。四组使用 vdn_1ff_128，共享无干预 A 前缀，继承在线及目标参数、优化器、回放和可恢复 RNG，再从 B 分叉。各阶段 2M 环境步，完整回合边界，训练预算为 A 2M + 4×8M。所有组使用现行任务切换重启探索计划。

软保护在唯一前馈层 A 筛选，取最近 32 局、VDN 状态加权活动的层内归一化得分严格大于 3 的单元，维护 A–D 历史并集。保护线性输入行和偏置及 GRU 三门输入列，优化器实际增量缩放为 0.1。TRHR 放在唯一前馈 ReLU，沿用已验证控制参数及槽位/可用目标动作的条件否决。组合组进入新阶段前，将历史保护名单同步给 TRHR，禁止对名单继续增加补偿；若已有补偿则保留。未保护组也计算自己的影子历史名单以支持诊断。各组的后续选择由各自模型产生。

同一检查点贪心评价所有已见任务（每任务 128 局、四个固定环境种子块），并评价下一未见任务；初始模型另评 B–E 用于 FWT。学习 AUC 用当前任务的起点评价、每 25k 环境步定期评价（32 局）和阶段末评价（128 局），按该阶段实测时间归一化。阶段记录同时包含旧任务平均胜率、ACC、BWT、FWT。

每次回放采样保留来源阶段标签，按 100 次 learner 更新记录每单元激活率、偏置补偿、裁剪后梯度及保护后实际增量。条件统计按来源任务 × 智能体槽位 × 可用目标动作输出正样本数和分母，后两者仍是实际控制器分组，任务来源仅用于诊断。记录新增补偿和首次观测到的持续唤醒：此前有实际补偿、同一阶段连续三个完整诊断窗口达到 5%。阶段末也保留未满窗口。历史名单与实际保护名单分别记录，避免在控制组把候选当成已保护单元。
