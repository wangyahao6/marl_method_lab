# TS5-1M 原生 TKPR-K1 自采历史 min-gap 消融

比较 0、0.25、0.5、0.75 和 1.0 五个阈值，训练种子为 2222、3535。双方镜像编队按 S → Z → C → 2S3Z → 2Z3C 排列，每阶段名义 1M 环境步，完整回合后切换。固定训练版本为 `8ba02fe065e89cce0044abee78999b4ad3b0a971`。五份配置仅 `topk_preference.min_gap` 不同。

## 训练与复用

- 使用原生 `topk_preference(k=1)`、单前馈层 VDN64、RMSprop、FT TD 回放与逐任务 ε。辅助损失权重、温度均为 1，旧 Q 缩放下限为 0.1，辅助批量跨历史任务共 8 局。
- 每个种子复用 11 月 24 日 TS5-1M CPR 批次的同一 S 完整训练状态及 S 成功池。Z 起各分支由自己的阶段末策略独立收集成功轨迹和旧 Q。E 的历史仅保存，后续没有训练阶段。
- 同批 gap=0.5 已有两个完成分支，配置、训练版本、共享模型和成功池指纹、Z–E 的存储采集策略均一致。其余四个阈值新增八个 Z–E 分支，名义新增 32M 环境步。
- 11 月 26 日固定历史池的 gap=0/0.5 使用 VDN-FT 成功数据，训练结果不纳入。TC 的 K1 也保持原归档，继续使用它自己的筛选协议。
- 原调度请求因固定工作树路径别名在训练前失败。带 `attempt002` 的新请求保留相同科学设置，修正调度参数中的运行路径。

## 评价与机制

每 25k 环境步用常规种子块对当前任务做 32 局贪心评价。阶段末按焦点种子块对已见任务各评估 128 局。单独进程用同一焦点种子块复核最终模型。AUC 使用阶段开始和周期性的常规评价梯形积分，最后一个点延伸至实际阶段末。ACC、BWT、FWT 从原始评价计数重算。

未筛候选是原生 K1 在 gap=0 下的全部严格排序对，实际保留对按各分支 gap 计算。有效状态覆盖率以存活且至少有两个合法动作的历史决策为分母。按训练采样的 episode 索引重建候选数，用逐更新日志累积保留数与保留集违反率。重放历史成功池并读取各阶段末检查点，另行计算候选集和保留集的违反率。当前 Q 排序反向或打平均计为违反；共享 S 可比较同一旧轨迹与旧 Q，后续历史测量随分支采集策略而变。
